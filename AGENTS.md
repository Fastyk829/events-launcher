# Версия лаунчера

По просьбе владельца при каждом новом наборе изменений лаунчера повышайте patch-версию перед передачей готовой сборки (например, 0.1.1 → 0.1.2). Синхронно обновляйте `package.json` и версию корневого пакета в `package-lock.json`. Не выпускайте изменённый установщик под прежней версией.
